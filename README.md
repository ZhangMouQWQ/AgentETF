# ETF 动量轮动 · 盯盘信号（GitHub Actions + Pages 自动版）

每个交易日**自动运行两次**（午盘休盘 + 收盘后），生成一个**随时可访问的网页**，告诉你**下个交易窗口**是否该调仓、重点买入哪只、有哪些风险。完全免费，无需服务器。

> 策略逻辑：不预测，只跟随强者。按"风险调整动量（涨幅÷波动率）"对21只行业/宽基ETF排名，买入前2-3名，动量为负则持现金。

---

## 网页包含什么

| 模块 | 内容 |
|------|------|
| 🎯 **买入推荐** | 两方案交集中的最优标的 + 板块 + 动量/波动/风险调整动量 |
| 📌 **操作指令** | 下个交易窗口：**卖出XX / 买入XX / 持有XX**，或"✅无需调仓" |
| ⚠️ **风险提醒** | 市场宽度、板块集中度、高波动、动量衰减等多维预警 |
| 📊 **完整排名** | 主推/高胜率两方案的风险调整动量排名表（含当日涨跌） |
| 🕐 **数据新鲜度** | 节假日/数据延迟时自动提示，避免用旧数据误导 |

## 部署步骤（约5分钟）

1. **新建 GitHub 仓库**（如 `etf-momentum`，Pages 需 Public 或 Pro 会员）
2. **上传本文件夹全部内容**（保持目录结构，见下）
3. **Actions 页手动 Run workflow 跑一次**（生成首个信号和持仓基准）
4. **Settings → Pages → Source 选 `main` / `/ (root)` → Save**，得到网址

```
etf-momentum/
├── strategy.py                  # 核心: 计算+生成网页
├── requirements.txt             # 依赖
├── index.html                   # 示例网页(Actions自动覆盖更新)
├── data.json                    # 持仓状态(用于调仓对比, Actions自动更新)
└── .github/workflows/update.yml # 定时任务
```

## ⭐ 一个月实盘操作手册（必读）

### 信号使用规则
- **以"收盘后"信号为准**：午盘信号用盘中价计算，下午可能变化，仅作参考；**收盘信号是定稿**，按它操作最稳。
- **当天建仓用午盘信号**：如果你想当天就动手，看午盘信号、下午13:00后买；**次日建仓看收盘信号**、上午9:30后买。
- **A股T+1**：收盘信号你本来就只能次日买，实测次日开盘买入反而常能吃到强势板块"低开"红利，无需担心延迟。

### 每次操作四步走
1. 打开网址，先看**操作指令**卡片
2. 若显示"✅无需调仓" → 今天什么都不做，关掉页面
3. 若显示"⚠️需要调仓" → 按"卖出/买入"清单执行
4. 扫一眼**风险提醒**，红灯(🔴)务必重视，黄灯(🟡)注意仓位

### 仓位与成本（重要）
- **单笔仓位**：建议每只ETF分配 1/3 资金（主推持3只），别全押一只
- **交易成本**：ETF佣金约万0.5~万3、**免印花税**，月调仓年化成本仅约0.24%，可忽略
- **分批建仓**：买入推荐若标注"高波动"或"当日下跌"，分2-3批买，别一次梭哈
- **留出现金**：动量为负的板块不买，对应仓位持有现金（货币基金/逆回购）

### 关键纪律
- **不预测、不抄底**：系统没让买的板块，跌再多也别碰
- **让利润奔跑**：不设止盈，持有到它跌出前3名再说
- **严格按调仓指令**：系统假设你完全按信号操作；若你自行加减仓，调仓对比会失准
- **节假日复核**：遇到长假，节后首个交易日务必打开网址复核信号（系统也会提示数据新鲜度）

### 一个月后如何评估
- 对照沪深300同期涨跌，看你的账户是否跑赢
- 统计这一个月里系统发出几次调仓指令、你执行了几次
- 重点复盘：风险提醒亮红灯时你是否照做了
- 若整体符合预期，可继续；若想调整周期/持仓数，改 `strategy.py` 顶部配置即可

## 数据源与容错
新浪财经公开接口（免费、无需 token）。已做三重容错：①网络抖动自动重试；②数据获取失败时保留上次结果、不生成错误信号；③节假日/数据延迟时提示新鲜度。仅用于个人学习研究。
