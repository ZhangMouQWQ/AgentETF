# ETF 动量轮动 · 盯盘信号（GitHub Actions + Pages 自动版）

每个交易日**自动运行两次**（午盘休盘 + 收盘后），生成一个**随时可访问的网页**，告诉你**下个交易窗口**是否该调仓、重点买入哪只、有哪些风险。完全免费，无需服务器。

> 策略逻辑：不预测，只跟随强者。按"风险调整动量（涨幅÷波动率）"对21只行业/宽基ETF排名，买入前2-3名，动量为负则持现金。

---

## 网页包含什么

每次更新后，打开网址即可看到：

| 模块 | 内容 |
|------|------|
| 🎯 **买入推荐** | 两方案交集中的最优标的 + 板块 + 动量/波动/风险调整动量 |
| 📌 **操作指令** | 下个交易窗口：**卖出XX / 买入XX / 持有XX**，或"✅无需调仓" |
| ⚠️ **风险提醒** | 市场宽度、板块集中度、高波动、动量衰减等多维预警 |
| 📊 **完整排名** | 主推/高胜率两方案的风险调整动量排名表（含当日涨跌） |

**双时段更新，覆盖每个交易窗口：**
- 午盘休盘（约 11:35 运行）→ 提示"**今日下午**（13:00开盘后）"如何操作
- 收盘后（约 15:05 运行）→ 提示"**下一交易日上午**（9:30开盘后）"如何操作

## 部署步骤（约5分钟）

### 1. 新建 GitHub 仓库
登录 GitHub，新建仓库，例如 `etf-momentum`（Pages 需 Public，或你是 Pro 会员）。

### 2. 上传本文件夹全部内容（保持目录结构）
```
etf-momentum/
├── strategy.py                    # 核心: 计算+生成网页
├── requirements.txt               # 依赖
├── index.html                     # 示例网页(Actions会自动覆盖更新)
├── data.json                      # 持仓状态(用于对比调仓, Actions自动更新)
└── .github/
    └── workflows/
        └── update.yml             # 定时任务
```
上传方式：
- **网页上传**：仓库页 → Add file → Upload files → 拖入整个文件夹
- **命令行**：
  ```bash
  git init && git add . && git commit -m "init"
  git branch -M main
  git remote add origin https://github.com/<用户名>/etf-momentum.git
  git push -u origin main
  ```

### 3. 手动跑一次，生成首个信号
仓库页 → **Actions** → 左侧选 **"更新ETF动量轮动信号"** → 右侧 **Run workflow** → 确认。
等待约1分钟，会自动生成并提交 `index.html` 和 `data.json`。

### 4. 开启 GitHub Pages
仓库页 → **Settings** → **Pages** → Source 选 `Deploy from a branch` → Branch 选 `main` / 目录 `/ (root)` → **Save**。
等1-2分钟，顶部会显示网址：`https://<用户名>.github.io/etf-momentum/`

✅ 完成！以后每个交易日的午盘和收盘后会自动更新，随时打开网址看最新操作指令。

## 定时规则（可按需修改）

编辑 `.github/workflows/update.yml` 的 `cron`（**UTC时间，北京=UTC+8**）：

| 当前设置 | cron | 北京时间 | 用途 |
|---------|------|---------|------|
| 午盘 | `35 3 * * 1-5` | 工作日 11:35 | 提示今日下午操作 |
| 收盘 | `5 7 * * 1-5` | 工作日 15:05 | 提示次日上午操作 |

> 注：GitHub Actions 定时可能有几分钟排队延迟，属正常。
